Adım 1 · Analiz Akışını Başlat

Bu akış dört adımdan oluşur: önce sistem servislerinin ayakta olduğunu doğrularsınız, ardından referans verilerini (bölgeler, rotalar, kare metadata'sı, saha raporları) yüklersiniz, sonra İHA görsellerini yükleyip otomatik tespit/track eşlemesini tetiklersiniz ve son olarak GLM-5.3 LLM İstihbarat Ajanı'nın ürettiği tehdit değerlendirme sonuçlarını görürsünüz.
